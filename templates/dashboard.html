Grover Policy Agent (GPA) for Quantum Sensor Circuits

Optimal Quantum Circuit Selection: Decision Norms & Architecture Details

How the Grover Policy Agent (GPA) identifies the best quantum sensor circuit according to fundamental metrology norms versus NISQ hardware constraints:

Base 2-Qubit QSC

THEORETICAL BEST

Attains maximum theoretical phase sensitivity (Heisenberg scaling) via direct squeezing unitaries.

  • Qubits: 2 sensing qubits \((q_0, q_1)\)
  • Target Phase Input: \(\phi = 0.50\text{ rad}\)
  • Optimal Angles: \(\theta_1^* = 0.00\text{ rad}, \theta_2^* = 0.00\text{ rad}\)
  • Peak QFI: 1.0000 (Heisenberg limit)
  • QPI Convergence: \(k = 50\) rotations (\(100\%\) success probability)
  • QPE Value \(V_\pi(s)\): \(0.9900\)
  • RL Reward \(R(k)\): \(10.0000\)
  • Hardware Norm: Requires ideal continuous squeezing \(S(\theta) = \exp(-i \frac{\theta}{2} Z \otimes Z)\)

Simplified 3-Qubit QSC

NISQ HARDWARE BEST

NISQ-ready decomposition replacing non-local squeezing with Controlled-\(V\) gates and an ancilla qubit.

  • Qubits: 2 sensing \((q_0, q_1)\) + 1 ancilla \((q_2)\)
  • Target Phase Input: \(\phi = 0.50\text{ rad}\)
  • Optimal Angles: \(\theta_1^* = 0.00\text{ rad}, \theta_2^* = 0.00\text{ rad}\)
  • Peak QFI: 0.5000 (Outperforms GAQA 0.45 by +11.1%)
  • QPI Convergence: \(k = 40\) rotations (Faster convergence)
  • QPE Value \(V_\pi(s)\): \(0.9890\)
  • RL Reward \(R(k)\): \(5.0000\)
  • Hardware Norm: Native 2-qubit CNOT and \(V = \frac{1+i}{2}\begin{pmatrix}1 & -i\\-i & 1\end{pmatrix}\)

System Architecture & Workflow

The prototype faithfully implements the mathematical architecture from Paper 161:

  • Quantum Sensor Circuits (QSC): Base 2-qubit circuit with squeezing matrix \(S(\theta)\) and NISQ-friendly Simplified 3-qubit circuit using Controlled-\(V\) and \(V^\dagger\) gates.
  • Quantum Phase Estimation (QPE): Evaluates policy value functions \(V_\pi(s)\) across counting qubit registers with exponential error decay \(O(2^{-t})\).
  • Quantum Policy Iteration (QPI): Employs Grover amplitude amplification to mark and amplify optimal metrology parameter policies that maximize the Quantum Fisher Information (QFI).
