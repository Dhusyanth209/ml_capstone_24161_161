Inference Pipeline & Simulation Execution

The inference.py module executes the end-to-end quantum simulation pipeline without hardcoded values. It simulates the quantum state evolution, evaluates Quantum Fisher Information (QFI), performs value estimation via Quantum Phase Estimation (QPE), applies Grover Policy Iteration (QPI) across rotation sweeps, and exports clean CSV datasets and high-resolution comparison plots.

Command-Line Execution Reference

You can execute the exact same pipeline directly via the command line or integrate it into existing automated workflows:

# Run full end-to-end pipeline:
python inference.py

# Or run via modular CLI subcommands:
python run_experiment.py --base-qsc
python run_experiment.py --simplified-qsc
python run_experiment.py --compare
